# ソフトウェア仕様書: Meowdoku Solver (cat_game_v29.py)

## 1. システム概要
本ソフトウェアは、ペンシルパズル「Meowdoku」（スターバトル形式のパズル）のスクリーンショット画像を自動解析し、バックトラッキングによる全解探索および多段階の論理ルールに基づく連鎖的推論（確定マスの連続導出）を行うCLIツールである。

### 主な特徴
- 画像自動取得・認識: 引数未指定時に指定された複数フォルダから最新のスクリーンショットを自動探索・選択し、OpenCVおよびk-meansクラスタリングを用いて盤面領域、色ブロック（ID）、シンボル（ネコ / Xマーク）を自動識別する。
- 連鎖的論理推論エンジン: 確定したマス情報を自動的に盤面へ反映し、論理推論のみで詰めることができる箇所までステップ順に連続出力する。
- 全解探索: 論理推論の出力完了後、盤面状態から到達可能なすべての猫の配置パターン（最大50件）を再帰探索（DFS）により導出し、最後に解の一例を出力する。
- 出力制御: -onlynext オプション指定時は、全解探索をスキップし最初の1手（単一ステップ）のみを出力して終了する。

## 2. 動作環境・依存ライブラリ
- 実行環境: Python 3.10 以上（Android Termux / Pydroid 3 / Linux / Windows / macOS）
- 依存ライブラリ: opencv-python (cv2), numpy
- 標準ライブラリ: sys, os, argparse, glob, json, collections

## 3. インターフェース仕様
### 3.1 コマンドライン引数
  python3 cat_game_v29.py [-onlynext] [IMAGE_PATH]

- IMAGE_PATH (任意): 解析対象の画像パス。省略時は自動検索。
- -onlynext (任意): 指定時、全解探索をスキップし、最初の「次の一手」のみを出力して終了。

### 3.2 自動ファイル検索仕様 (IMAGE_PATH 未指定時)
以下のディレクトリ一覧を順次探索し、最もタイムスタンプが新しい画像（.png, .jpg, .jpeg）を自動選択する。
1. /storage/emulated/0/Download/
2. /storage/emulated/0/Pictures/Screenshots/
3. /storage/emulated/0/DCIM/Screenshots/
4. カレントディレクトリ (./)

## 4. 詳細機能仕様 & デバッグ出力
- デバッグ・データ保存先: スクリプト配置ディレクトリ直下の `temp_py/`
- 保存ファイル: `board_cropped.png`, `debug_grid.png`, `debug_recognized.png`, `cells_data.json`

## 5. 連鎖推論ロジック仕様
1. 現在の盤面状態から論理確定手（猫またはX）を1ステップ探索。
2. 確定手が存在する場合、そのマスを盤面情報に追加・更新し、次のステップへ遷移。
3. 新たな確定手が導出できなくなるか、または全セルが確定するまで連続してループ処理を実行。

## 6. 標準出力仕様 (Terminal Console Output)

1. 【デバッグ出力】
   - 自動選択画像名、解析盤面サイズ

2. 【論理推論による連鎖手番の導出】
   - ステップ 1: 【確定】{C または X} になるマス ({対象マス数}マス)
     - 対象: {R01C03 などのマス表記}
     - [理由] {確定に至った論理的理由}
   - ステップ 2: ... (推論が続く限り連続表示)
   - 終了メッセージ: これ以上の確定手を論理推論のみで導出できませんでした。

3. 【全解探索 (すべての猫の位置の検討)】 ※ -onlynext 未指定時のみ最後に表示
   - ★ 解の一例 (すべての猫の配置パターン):
     R01C03, R02C08, R03C01, R04C05, ...
